# Step 1: こんにちは、Tello！

## 🎯 このステップの目標

Telloドローンに初めて接続し、バッテリー残量を取得してみましょう。
これが、あなたとTelloの最初のコミュニケーションです！

> **💡 Python初心者の方へ**: このレッスンで使う「クラス」「オブジェクト」「f文字列」などの概念がよくわからない場合は、先に [Step 0: Pythonの基本](../step-0-python-basics) を学習することをお勧めします！

## 📝 学習内容

*   Telloドローンとの接続方法
*   `djitellopy` ライブラリの基本的な使い方
*   ドローンの状態情報（バッテリー残量など）の取得方法

## 🔧 準備

### 必要なライブラリのインストール

まず、Pythonで Tello を制御するためのライブラリをインストールします。

```bash
pip install djitellopy
```

### Telloとの接続

1. Telloドローンの電源を入れます（本体側面のボタンを押します）
2. ドローンのLEDが点滅を始めたら、PCのWi-Fi設定画面を開きます
3. `TELLO-XXXXXX` という名前のWi-Fiネットワークを探して接続します
   - パスワードは不要です

## 💻 サンプルコード

`hello_tello.py` というファイル名で、以下のコードを作成してみましょう。

```python
from djitellopy import Tello

# Telloオブジェクトを作成
tello = Tello()

# Telloに接続
print("Telloに接続中...")
tello.connect()

# バッテリー残量を取得
battery = tello.get_battery()
print(f"バッテリー残量: {battery}%")

# 接続終了
print("接続を終了しました。")
```

## 🚀 実行方法

1. Telloのスイッチを入れて、Wi-Fiに接続します
2. ターミナル（コマンドプロンプト）で以下のコマンドを実行します：

```bash
python hello_tello.py
```

## ✅ 期待される結果

正常に動作すると、以下のような出力が表示されます：

```
Telloに接続中...
バッテリー残量: 85%
接続を終了しました。
```

※ バッテリー残量の数値は、ドローンの実際の残量によって変わります。

## 🔍 コードの解説

### インポート文

```python
from djitellopy import Tello
```

*   **`from djitellopy`**: `djitellopy` というライブラリ（パッケージ）の中から
*   **`import Tello`**: `Tello` というクラス（設計図）を読み込む

これは、他の人が作ってくれた便利な道具箱（ライブラリ）から、
Telloドローンを操作するための道具（クラス）を取り出しているイメージです。

💡 **初心者向け補足**: インポートとは？
*   プログラムで使う「部品」を他のファイルから持ってくること
*   `djitellopy` は、Telloドローンを簡単に操作できるようにしてくれるライブラリ
*   自分で全部作るのは大変なので、他の人が作った便利なライブラリを使います

### オブジェクトの作成

```python
tello = Tello()
```

*   **`Tello()`**: Telloクラス（設計図）から、実際のオブジェクト（実体）を作る
*   **`tello =`**: 作ったオブジェクトに `tello` という名前をつける（変数に代入）

💡 **初心者向け補足**: クラスとオブジェクトとは？
*   **クラス**: 設計図（例: 「犬」という概念）
*   **オブジェクト**: 設計図から作った実物（例: 「ポチ」という名前の具体的な犬）
*   `Tello()` で、ドローンを操作するための「インスタンス」（実体）を作っています

### メソッドの呼び出し

```python
tello.connect()
```

*   **`tello`**: 先ほど作ったオブジェクト
*   **`.connect()`**: オブジェクトが持っている「メソッド」（機能、動作）を実行する
*   **`connect`**: 「接続する」という意味のメソッド

これは、「telloくん、ドローンに接続してね！」とお願いしているイメージです。

💡 **初心者向け補足**: メソッドとは？
*   オブジェクトができる「動作」や「機能」のこと
*   `connect()` は「接続する」という動作
*   `.` （ドット）でオブジェクトとメソッドをつなぐ

### 値の取得

```python
battery = tello.get_battery()
```

*   **`tello.get_battery()`**: telloオブジェクトの `get_battery` メソッドを呼び出す
*   **`get_battery`**: 「バッテリー残量を取得する」という意味
*   **`battery =`**: 取得した値を `battery` という変数に保存する

返り値は整数（例: 85）で、パーセンテージを表します。

### f文字列による出力

```python
print(f"バッテリー残量: {battery}%")
```

*   **`print()`**: 画面に文字を表示する関数
*   **`f"..."`**: f文字列（フォーマット文字列）
*   **`{battery}`**: 変数 `battery` の値を埋め込む場所

💡 **初心者向け補足**: f文字列とは？
*   文字列の中に変数の値を簡単に埋め込める便利な書き方
*   文字列の前に `f` をつける
*   変数を `{ }` で囲む

**f文字列の例**:
```python
# 古い書き方（読みにくい）
print("バッテリー残量: " + str(battery) + "%")

# f文字列（読みやすい！）
print(f"バッテリー残量: {battery}%")
```

どちらも同じ結果ですが、f文字列の方がずっと読みやすく、書きやすいです！

### 全体の流れ

1.  **ライブラリをインポート**: Telloクラスを使えるようにする
2.  **オブジェクトを作成**: Telloクラスから実体を作る
3.  **接続**: ドローンとの通信を開始する
4.  **データ取得**: バッテリー残量を取得する
5.  **表示**: f文字列を使って画面に表示する

## ⚠️ トラブルシューティング

### 「接続できない」というエラーが出る場合

*   PCがTelloのWi-Fiに正しく接続されているか確認してください
*   ファイアウォールがブロックしている可能性があります
*   ドローンの電源を一度切って、再度入れ直してみてください

### バッテリー残量が20%以下の場合

*   安全のため、バッテリーを充電してから実験を続けましょう
