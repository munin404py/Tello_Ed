## 🗺️ SLAMとは？

**SLAM** = **S**imultaneous **L**ocalization **A**nd **M**apping

日本語では「**自己位置推定と地図作成の同時実行**」と訳されます。

### 簡単に言うと

ロボットやドローンが、以下の2つを**同時に**行う技術です：

1. **自己位置推定（Localization）**
   - 「今、自分はどこにいるのか？」を知る

2. **地図作成（Mapping）**
   - 「周りの環境はどうなっているのか？」を記録する

### なぜ「同時」が難しいのか？

通常、位置を知るには地図が必要で、地図を作るには位置が必要です。
これは「**鶏が先か卵が先か**」のような問題です。

SLAMは、この2つを同時に解決する巧妙な技術なのです！

## 🎯 SLAMの実用例

### 1. ロボット掃除機（ルンバなど）

*   部屋の中を移動しながら、部屋の形を学習
*   既に掃除した場所を覚えて、効率的に動く

### 2. 自動運転車

*   走行しながら周囲の地図を作成
*   自分の位置を正確に把握して安全に走行

### 3. ドローン

*   GPS が使えない屋内でも自律飛行
*   カメラやセンサーで環境を認識

### 4. AR/VRアプリ

*   スマートフォンやヘッドセットで空間を認識
*   仮想オブジェクトを現実空間に配置

## 🔍 SLAMの基本的な仕組み

### 1. センサーでデータを取得

*   **カメラ**: 画像・映像
*   **LiDAR**: レーザーで距離を測定
*   **IMU**: 加速度・角速度を測定

### 2. 特徴点を抽出

画像から特徴的な点（コーナー、エッジなど）を見つけます。

### 3. 特徴点をマッチング

連続するフレーム間で同じ特徴点を見つけて対応付けます。

### 4. カメラの動きを推定

特徴点の移動から、カメラ（ドローン）がどう動いたかを計算します。

### 5. 3D地図を作成

複数の視点から見た情報を統合して、3D空間の地図を作ります。

### 6. 位置の最適化

過去のデータと新しいデータを照らし合わせて、位置推定の精度を高めます。

## 📚 SLAMの種類

### Visual SLAM（視覚ベースのSLAM）

*   **カメラだけ**を使うSLAM
*   例: ORB-SLAM、LSD-SLAM
*   コストが低いが、計算量が多い

### LiDAR SLAM

*   **レーザースキャナ**を使うSLAM
*   例: Cartographer、LOAM
*   高精度だが、センサーが高価

### Visual-Inertial SLAM

*   **カメラ + IMU（慣性センサー）** を組み合わせたSLAM
*   例: VINS-Mono、ORB-SLAM3
*   精度と安定性が向上

## 🎓 `slam-ad` プロジェクトについて

`munin404py/slam-ad` は、おそらく以下のような技術を使っています：

*   Visual SLAM または Visual-Inertial SLAM
*   Telloのカメラ映像を使った3D復元
*   リアルタイムでの地図作成と位置推定
*   Web技術を使った可視化

このプロジェクトを理解するには、以下の知識がさらに必要です：

1. **線形代数**: 行列、ベクトル、座標変換
2. **コンピュータビジョン**: 特徴点抽出、エピポーラ幾何
3. **確率・統計**: カルマンフィルタ、粒子フィルタ
4. **最適化**: グラフ最適化、バンドル調整

### プロジェクト2: 特徴点の可視化

カメラ映像から特徴点（コーナーなど）を抽出して、画面に表示してみましょう。

ヒント: OpenCVの `cv2.goodFeaturesToTrack()` を使う

```python
import cv2
import numpy as np

frame = tello.get_frame_read().frame
gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)

# 特徴点を検出
corners = cv2.goodFeaturesToTrack(gray, maxCorners=100, qualityLevel=0.3, minDistance=7)

if corners is not None:
    for corner in corners:
        x, y = corner.ravel()
        cv2.circle(frame, (int(x), int(y)), 3, (0, 255, 0), -1)

cv2.imshow("Feature Points", frame)
```
