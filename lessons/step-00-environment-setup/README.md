## 1. Pythonとは？

**Python（パイソン）** は、プログラミング言語の一つです。
人間が書いた命令を、コンピュータが理解できる形に変換して実行してくれるツールです。

### Pythonの特徴
*   **読みやすい**: 英語に近い文法で、初心者にも分かりやすい
*   **人気が高い**: 世界中で使われていて、困ったときの情報が豊富
*   **何でもできる**: Webアプリ、AI、ドローン制御など、幅広い用途に使える

## 2. Pythonをインストールしよう

### Windows の場合

1. **公式サイトにアクセス**
   - [https://www.python.org/](https://www.python.org/) を開きます
   - 「Downloads」をクリック
   - 「Download Python 3.x.x」というボタンをクリック

2. **インストーラーを実行**
   - ダウンロードしたファイルをダブルクリック
   - **重要**: 「Add Python to PATH」にチェックを入れる ✅
   - 「Install Now」をクリック

3. **インストール完認**
   - コマンドプロンプトを開く（Windowsキー + R → `cmd` と入力 → Enter）
   - 以下のコマンドを入力して、Enterを押す：
   ```
   python --version
   ```
   - `Python 3.x.x` のように表示されればOK！

### macOS の場合

1. **Homebrewをインストール（まだの場合）**
   - ターミナルを開く（アプリケーション → ユーティリティ → ターミナル）
   - 以下のコマンドを入力：
   ```bash
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   ```

2. **Pythonをインストール**
   ```bash
   brew install python
   ```

3. **インストール確認**
   ```bash
   python3 --version
   ```

### Linux (Ubuntu/Debian) の場合

1. **ターミナルを開く**

2. **Pythonをインストール**
   ```bash
   sudo apt update
   sudo apt install python3 python3-pip
   ```

3. **インストール確認**
   ```bash
   python3 --version
   ```

## 3. テキストエディタを準備しよう

プログラムを書くためのツールが必要です。**Visual Studio Code (VS Code)** がおすすめです。

### VS Code のインストール

1. **公式サイトにアクセス**
   - [https://code.visualstudio.com/](https://code.visualstudio.com/) を開く
   - 「Download」をクリックして、あなたのOS用のものをダウンロード

2. **インストーラーを実行**
   - ダウンロードしたファイルを開いて、指示に従ってインストール

3. **日本語化（任意）**
   - VS Code を起動
   - 左側のアイコンから「Extensions（拡張機能）」をクリック（四角が4つ並んだアイコン）
   - 検索バーに「Japanese Language Pack」と入力
   - 「Install」をクリック
   - VS Code を再起動

4. **Python拡張機能をインストール**
   - 同じく「Extensions」から「Python」と検索
   - Microsoft製の「Python」拡張機能をインストール

## 4. pip（ピップ）とは？

**pip** は、Pythonの「ライブラリ」を簡単にインストールできるツールです。

### ライブラリって何？

ライブラリは、**他の人が作ってくれた便利な機能の集まり** です。
例えば：
*   `djitellopy` → Telloドローンを制御する機能
*   `opencv-python` → 画像や映像を処理する機能
*   `fastapi` → Web APIを作る機能

自分で全部作るのは大変なので、ライブラリを使って効率よくプログラミングします。

### pip の使い方

#### ライブラリをインストールする
```bash
pip install ライブラリ名
```

例：
```bash
pip install djitellopy
```

#### インストール済みのライブラリを確認する
```bash
pip list
```

#### ライブラリをアップデートする
```bash
pip install --upgrade ライブラリ名
```

#### ライブラリをアンインストールする
```bash
pip uninstall ライブラリ名
```

## 5. ポートとネットワークの基本

### ポートって何？

**ポート** は、コンピュータの「出入り口」のようなものです。

例えば、アパートに100号室、200号室があるように、
コンピュータにも「ポート番号」で区別される複数の出入り口があります。

*   **ポート8000**: Web APIサーバーが使う出入り口
*   **ポート80**: 通常のWebサイトが使う出入り口
*   **ポート8889**: Telloドローンとの通信に使う出入り口

### なぜポートが必要？

1台のコンピュータで複数のプログラムが同時にネットワーク通信をするとき、
どのプログラムへのデータかを区別するために、ポート番号を使います。

### ポートを「開く」とは？

プログラムが「このポート番号で通信を待ち受けます」と宣言することを、
**ポートを開く** と言います。

例：
```python
uvicorn.run(app, host="0.0.0.0", port=8000)
```
→ ポート8000番で待ち受け、ブラウザからアクセスできるようにする

### ファイアウォールについて

**ファイアウォール** は、コンピュータを守る「門番」です。
不審な通信をブロックしてくれますが、時々、必要な通信までブロックすることがあります。

もしプログラムが動かない場合、ファイアウォールの設定を確認してみましょう。

#### Windowsの場合
1. 「コントロールパネル」→「システムとセキュリティ」→「Windows Defender ファイアウォール」
2. 「アプリケーションの許可」から、Pythonを探して許可する

#### macOSの場合
1. 「システム環境設定」→「セキュリティとプライバシー」→「ファイアウォール」
2. 必要に応じてPythonを許可する

## 6. 仮想環境について（少し高度な話）

**仮想環境** は、プロジェクトごとに独立したPython環境を作る仕組みです。

### なぜ必要？

例えば：
*   プロジェクトAでは `djitellopy` のバージョン1.0を使いたい
*   プロジェクトBでは `djitellopy` のバージョン2.0を使いたい

このような場合、仮想環境を使うと、プロジェクトごとに異なるバージョンを管理できます。

### 仮想環境の作り方（任意）

この教材では仮想環境を使わなくても大丈夫ですが、興味があれば試してみてください。

#### 1. 仮想環境を作成
```bash
python -m venv tello_env
```
（`tello_env` という名前の仮想環境が作られます）

#### 2. 仮想環境を有効化

**Windows:**
```bash
tello_env\Scripts\activate
```

**macOS/Linux:**
```bash
source tello_env/bin/activate
```

有効化すると、ターミナルの先頭に `(tello_env)` と表示されます。

#### 3. ライブラリをインストール
```bash
pip install djitellopy
```

#### 4. 仮想環境を無効化
```bash
deactivate
```

## 7. 最初のPythonプログラムを書いてみよう

それでは、簡単なプログラムを書いて動かしてみましょう！

### 手順

1. **新しいフォルダを作る**
   - デスクトップなどに `tello_practice` というフォルダを作成

2. **VS Codeでフォルダを開く**
   - VS Code を起動
   - 「File」→「Open Folder」→ `tello_practice` を選択

3. **新しいファイルを作る**
   - VS Code の左側で「New File」をクリック
   - ファイル名を `hello.py` にする

4. **コードを書く**
   ```python
   print("こんにちは、世界！")
   print("私の名前は太郎です。")
   
   # 変数を使ってみる
   name = "花子"
   age = 20
   print(f"{name}さんは{age}歳です。")
   ```

5. **実行する**
   - VS Code で「Terminal」→「New Terminal」を選択
   - ターミナルに以下を入力してEnterを押す：
   ```bash
   python hello.py
   ```

6. **結果を確認**
   ```
   こんにちは、世界！
   私の名前は太郎です。
   花子さんは20歳です。
   ```

## 8. よくあるエラーと対処法

### `'python' は、内部コマンドまたは外部コマンド...として認識されていません。`

**原因**: PythonがPATHに追加されていない

**対処法**:
*   Pythonを再インストールして、「Add Python to PATH」にチェックを入れる
*   または、`python` の代わりに `python3` と入力してみる

### `pip: command not found`

**原因**: pipがインストールされていない

**対処法**:
```bash
python -m ensurepip --upgrade
```

### `ModuleNotFoundError: No module named 'xxxx'`

**原因**: 必要なライブラリがインストールされていない

**対処法**:
```bash
pip install xxxx
```
（`xxxx` の部分を、エラーメッセージに出ているモジュール名に置き換える）
